# Run locally
1. Open `index.html` in a browser (or run `python3 -m http.server` here and visit http://localhost:8000).
2. Add photos to `assets/images/`: hero.jpg, about.jpg, germany.jpg, uae.jpg, singapore.jpg, gcc.jpg (use royalty-free sources such as Unsplash; hero ~1920px wide, others ~1000px).
3. Search for `EDIT` / `PLACEHOLDER` in index.html and js/script.js to set company name, contacts, WhatsApp number, stats, testimonials.
4. The form is frontend-only: wire it to an API in js/script.js (see the BACKEND REQUIRED comment).
